# SHONGJOG — GSD Project Context
## Professional UI/UX Refinement & Prose De-Slopping

### Executive Directive
Transform SHONGJOG from an initial hackathon/vibe-coded aesthetic into a mature, globally presentable, production-grade emergency technology platform. The product must evoke the institutional rigor of UN OCHA, Crisis Cleanup, and modern geospatial command software.

### Key Tenets
1. **Unslop Prose**: Eliminate AI-generated tropes, breathless marketing language, and out-of-place hackathon badges. Adopt crisp, calm, authoritative emergency-management terminology.
2. **De-Vibecode UI**: Remove blurry neon glow filters, radioactive halos, and tacky animations. Introduce crisp hairline borders, calm neutrals, precision typography, and rugged, high-contrast emergency UI patterns.
3. **Institutional Polish**: Elevate data density, typography scales, tabular figures, and keyboard navigation.
4. **Safety & Invariants**: Retain 100% test pass rate across all 38 unit, integration, and Playwright multi-viewport browser tests.
